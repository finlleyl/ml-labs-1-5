## Как устроен эксперимент

- Данные разбиты на train и test в отношении 80/20. Везде `random_state=22`, классификация стратифицирована.
- Параметры подбираются через `GridSearchCV` только на train. Тест используется для итоговой оценки.
- Для классификации основная метрика: ROC-AUC. Также считаются F1 для `bad` и accuracy.
- Для регрессии основная метрика: RMSE в МПа. Дополнительно выводятся MAE и R².
- Собственные алгоритмы находятся в `src/models/`. Они не вызывают sklearn для обучения или прогноза.
- В своем случайном лесе используется не больше 50 деревьев. Иначе версия на чистом Python обучается слишком долго.

## Результаты после настройки

В таблице указаны метрики на test. Для ROC-AUC выше лучше, для RMSE ниже лучше.

| Алгоритм | ROC-AUC sklearn | ROC-AUC своя | RMSE sklearn, МПа | RMSE своя, МПа |
|---|---:|---:|---:|---:|
| KNN | 0,9361 | 0,9361 | 7,787 | 7,787 |
| Логистическая / линейная регрессия | 0,8696 | 0,8704 | 7,531 | 7,531 |
| Решающее дерево | 0,9335 | 0,9270 | 5,745 | 5,439 |
| Случайный лес | 0,9965 | 0,9957 | **4,515** | **4,556** |
| Градиентный бустинг | **0,9974** | 0,9952 | 4,668 | 4,620 |

Лучший ROC-AUC дал градиентный бустинг sklearn: 0,9974. Наименьший RMSE у случайного леса sklearn: 4,515 МПа. Тестовые выборки небольшие, поэтому близкие значения не стоит считать доказательством преимущества одной модели над другой.

Полная таблица: `results/all_results.csv`. Изменения относительно бейзлайна: `results/summary_metrics.csv`. Графики лежат в `results/`.

## Запуск

```bash
python3 -m venv .venv
source .venv/bin/activate
python -m pip install -r requirements.txt

# Тесты собственных алгоритмов
python -m unittest discover -s tests -v

# Выполнить пять работ, затем общее сравнение
python scripts/run_notebooks.py

# Проверить ячейки, комментарии и CSV
python scripts/check_project.py
```

При ручном запуске `06_comparison.ipynb` нужно открывать последним: он читает результаты остальных работ из `results/`.

Время `fit_seconds` для улучшенной sklearn-модели включает весь поиск по сетке. У собственных моделей и sklearn могут отличаться детали оптимизации, поэтому небольшие расхождения в метриках нормальны.
