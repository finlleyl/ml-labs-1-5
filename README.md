## Датасеты

| Задача | Датасет | Практический смысл | Объекты / признаки |

| Классификация | [Ionosphere, UCI](https://archive.ics.uci.edu/dataset/52/ionosphere) | Отличать радиосигналы со структурой в ионосфере от проходящих сигналов | 351 / 34 |

Исходные данные и файлы с описанием находятся в `data/`, поэтому расчёты не требуют повторного скачивания. Для Ionosphere целевой класс закодирован как `bad=1`, `good=0`.

## Как устроен эксперимент

- Разбиение 80% / 20%, `random_state=22`; для классификации используется стратификация.
- Подбор параметров — `GridSearchCV` с пятью блоками только на обучающей части.
- Основная метрика классификации — ROC-AUC; дополнительно считаются F1 по классу `bad` и accuracy.
- Основная метрика регрессии — RMSE в МПа; дополнительно считаются MAE и R².
- Одни и те же разбиения и метрики используются во всех работах.
- Свои алгоритмы реализованы на NumPy в `src/models/`; sklearn не подменяет собственные вычисления.
- Для собственного случайного леса задано не более 50 деревьев, чтобы расчёт на чистом Python оставался быстрым. Это ограничение отмечено в notebook и в сохранённых параметрах.

## Запуск

```bash
python3 -m venv .venv
source .venv/bin/activate
python -m pip install -r requirements.txt

# Проверка собственных алгоритмов
python -m unittest discover -s tests -v

# Повторное выполнение всех notebook-файлов по порядку
python scripts/run_notebooks.py

# Проверка структуры, выполнения ячеек и итоговых CSV
python scripts/check_project.py
```

Notebook-файлы можно открыть и выполнить вручную через Jupyter. Запускать итоговый `06_comparison.ipynb` нужно после пяти лабораторных: он читает их CSV из `results/`.
